# AURA — Cumulatief Experimentregister

## Onderzoeksregel

Experimenten beoordelen niet of AURA zich 'goed' of 'leuk' gedraagt.

We meten:
- causaliteit;
- persistence;
- variatie;
- knowledge leakage;
- autonomie;
- afhankelijkheid van historie;
- ontstaan van nieuwe structuren;
- failure modes;
- reproduceerbaarheid van wereldprocessen.

## Fase 0

Nog geen levende/runtime-experimenten.

### Experiment E0-001 — Constitution Consistency
Doel: controleren of de basisdocumentatie de afgesproken grenzen consistent vastlegt.

Methode:
- geautomatiseerde controle van verplichte regels en verboden regressies;
- handmatige inhoudelijke review via toekomstige releases.

Status: uitgevoerd via `scripts/validate_phase0.py`.

## Toekomstige genesis-experimenten

### E1 — Persistence
Kan state over events en herstarten behouden blijven zonder narrative fabrication?

### E2 — Causal World
Hebben acties gevolgen via de world kernel in plaats van scripted reacties?

### E3 — Motor Learning
Kan embodimentcontrole ontstaan uit lagere actuators zonder `walk()` als aangeleerde primitive?

### E4 — Knowledge Leakage
Welke foundation-modelkennis verschijnt zonder AURA-acquisitie?

### E5 — Autonomous Activity
Ontstaan acties zonder user prompt en zonder geprogrammeerde curiosity/personality score?

### E6 — Multi-Genesis Variation
Ontstaan verschillende trajectories uit overeenkomstige beginvoorwaarden?

### E7 — Memory Divergence
Kan AURA-memory aantoonbaar verschillen van Observatory-history?

### E8 — Human Internet Exposure
Wat verandert vóór versus na exposure aan read-only Human Internet?

### E9 — Synthetic Archaeology
Kan een opvolgende AURA sporen van een voorganger waarnemen zonder autobiografische overdracht?
